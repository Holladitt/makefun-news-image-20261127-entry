Entry untuk bounty [Sum up 27 November's world news in one image](https://make.fun/bounty/news-image-20261127) ($100, top 50 berbagi hadiah; 1st $20).

Program `main.ts` (Node 22) menulis satu gambar ke `/output/entry.png` — koran satu halaman yang merangkum berita dunia hari Jumat 27 November 2026. PNG maksimal 1 MiB dan 1024×1024 px, tanpa network, deterministik (dua run menulis byte yang sama).

## Menjalankan

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
